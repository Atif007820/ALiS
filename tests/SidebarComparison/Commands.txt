Recommended command format
------------------------------------------------------------
npm run sidebar -- --headed --product= 1,2,3,4,5,6 --parallel 3

Short format also works, but npm may show warnings for --product:
npm run sidebar --headed --product= 1,2,3,4,5,6 --parallel 3


Supported options
------------------------------------------------------------
--headed              Run browser in headed mode
--product= 1,2,3      Run only selected product numbers
--parallel 3          Run selected product comparisons with 3 workers
--parallel            Use config/runSettings.json parallelWorkers
--project=chromium    Run a specific Playwright project
--list                List tests without running them

Edit product credentials
------------------------------------------------------------
Each product has separate URL A and URL B credentials in:
C:\Users\mohd.jamal\Downloads\Playwright\tests\SidebarComparison\config\url.js

Example:
urlA: {
  loginUrl: '...',
  username: '...',
  password: '...',
  businessUnit: '...',
  label: 'NVRCP URL A',
}


Notes
------------------------------------------------------------
- Product names can be changed anytime in config\url.js.
- Product numbers like --product= 1,2,3 will still work even if names change.
- A selected product will run even if enabled is false.
- Numeric command style preferred:
  --product= 1,2,3,4,5,6
