Framework folder

cd C:\Users\mohd.jamal\Downloads\Playwright\tests\SidebarComparison


Recommended command format
------------------------------------------------------------
Use "--" after npm run sidebar.
Do not add a space after --product=.

Run ALL configured products:
npm run sidebar -- --product=ALL --project=chromium --parallel 3

Run ALL configured products in headed mode:
npm run sidebar -- --product=ALL --headed --project=chromium --parallel 3

List ALL configured products without running:
npm run sidebar -- --product=ALL --project=chromium --parallel 3 --list


Supported options
------------------------------------------------------------
--product=ALL        Run all configured products from config\url.js
--product=1          Run Product 1
--product=1,2,3      Run selected product numbers
--headed             Run browser in headed mode
--project=chromium   Run a specific Playwright project
--parallel 3         Run selected product comparisons with 3 workers
--parallel           Use config\runSettings.json parallelWorkers
--list               List tests without running them


Product number mapping
------------------------------------------------------------
1 = Product 1
2 = Product 2
3 = Product 3
4 = Product 4
5 = Product 5
6 = Product 6

Notes
------------------------------------------------------------
- --product=ALL now runs every configured product in config\url.js.
- Product numbers like --product=1,2,3 continue to work even if product names are changed.
- A selected product number runs even if that product has enabled: false.
- If --product is not provided, the framework also runs all enabled products by default.
