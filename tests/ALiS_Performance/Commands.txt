ALiS Performance Commands
=========================

Run From Framework Folder
-------------------------
cd C:\Users\mohd.jamal\Downloads\Playwright\tests\ALiS_Performance

List Available JMeter Scripts
-----------------------------
npm run perf:list

Non-GUI Run
-----------
Runs the JMeter script in CLI/non-GUI mode using settings saved inside the .jmx.

npm run perf -- --script=LNI_PREPROD.jmx

Equivalent commands:

npm run perf:run -- --script=LNI_PREPROD.jmx
npm run perf:non-gui -- --script=LNI_PREPROD.jmx

Nested script example:

npm run perf -- --script="LNI/Licensee Search.jmx"

Non-GUI Run With Optional Load Profile
--------------------------------------
npm run perf -- --script=LNI_PREPROD.jmx --profile=smoke

Override profile values:

npm run perf -- --script=LNI_PREPROD.jmx --profile=smoke --threads=5 --duration=60

If --profile is not provided, no profile values are passed and JMeter uses the settings saved directly in the .jmx.
When a profile is provided, the framework applies it to a temporary runtime copy because the source JMX files may contain hardcoded Thread Group values. The source JMX is never changed.

Available Load Profiles
-----------------------
All durations and ramp-up values are in seconds.

smoke       1 thread,    1 ramp-up,    30 duration
load       50 threads,  60 ramp-up,   600 duration
stress    250 threads, 120 ramp-up,   900 duration
spike     250 threads,   5 ramp-up,   300 duration
endurance  50 threads, 300 ramp-up, 14400 duration (4 hours)

Examples:

npm run perf:non-gui -- --script=LNI_PREPROD.jmx --profile=load
npm run perf:non-gui -- --script=LNI_PREPROD.jmx --profile=stress
npm run perf:non-gui -- --script=LNI_PREPROD.jmx --profile=spike
npm run perf:non-gui -- --script=LNI_PREPROD.jmx --profile=endurance

Same Script With Multiple Profiles
----------------------------------
Separate profiles with commas. The framework runs the script once per profile.

Non-GUI:

npm run perf:non-gui -- --script=LNI_PREPROD.jmx --profile=spike,stress --parallel=2

GUI:

npm run perf:gui -- --script=LNI_PREPROD.jmx --profile=spike,stress --parallel=2

--parallel=2 allows both profile runs to execute at the same time.
Each profile has an isolated output folder:

results/LNI_PREPROD/spike/<timestamp>/
results/LNI_PREPROD/stress/<timestamp>/

Multiple scripts and multiple profiles create every combination. For example,
2 scripts with 2 profiles create 4 independent runs.

Parallel Execution - GUI and Non-GUI
------------------------------------
Separate script names with semicolons. --parallel controls the maximum runs executing together.

Non-GUI parallel run:

npm run perf:non-gui -- --script="LNI/Inspection_Search.jmx;LNI_Test.jmx" --profile=load --parallel=2

GUI parallel run:

npm run perf:gui -- --script="LNI/Inspection_Search.jmx;LNI_Test.jmx" --profile=load --parallel=2

The space form is also supported:

npm run perf:gui -- --script="LNI/Inspection_Search.jmx;LNI_Test.jmx" --profile=load --parallel 2

The plural --scripts option remains supported as an alias for --script.

Run every discovered JMX script:

npm run perf:parallel -- --script=ALL --parallel=3

Each GUI and non-GUI script/profile run receives its own result folder, JTL, logs, Excel report, and Playwright report.

Control parallel execution in config/runConfig.js:

parallelExecution: true      Enables parallel execution for GUI and non-GUI when multiple scripts are supplied.
parallelWorkers: 3           Default maximum runs executing together when --parallel is omitted.

Set parallelExecution to false to process the supplied scripts sequentially.
An explicit --parallel value overrides both runConfig settings for that command.
Use --parallel=false to force a single sequential run.

Report Auto Open
----------------
Excel report auto-open is enabled by default.
The Playwright-style HTML report is generated by the Node runner and opens in Chrome by default.
It includes a Download Excel Report link for the current run.

Control it here:

config/runConfig.js
openExcelReport
openPlaywrightReport
attachReports

GUI Mode
--------
Opens the script in JMeter GUI.
Auto-start is enabled by default from config/runConfig.js.

npm run jmeter:gui -- --script=LNI_PREPROD.jmx

Equivalent command:

npm run perf:gui -- --script=LNI_PREPROD.jmx

GUI run with a load profile:

npm run perf:gui -- --script=LNI_PREPROD.jmx --profile=smoke

GUI profile with command-line overrides:

npm run perf:gui -- --script=LNI_PREPROD.jmx --profile=smoke --threads=5 --duration=60

GUI parallel run:

npm run perf:gui -- --script="LNI/Inspection_Search.jmx;LNI_Test.jmx" --profile=load --parallel=2

With no --profile or load overrides, GUI mode uses the settings saved in the JMX.
After GUI execution and auto-close, the Excel and Playwright reports are generated and opened automatically.
Keep guiWaitForExit=true for automatic GUI report generation.

Disable GUI auto-start for one run:

npm run jmeter:gui -- --script=LNI_PREPROD.jmx --auto-start=false

Disable GUI auto-close for one run:

npm run jmeter:gui -- --script=LNI_PREPROD.jmx --auto-close=false

Change the default GUI auto-start setting:

config/runConfig.js
guiAutoStart
guiAutoStartDelayMs
guiAutoClose
guiWaitForExit

Generate Excel Report From Existing JTL
---------------------------------------
npm run perf:report -- --jtl=results/LNI_PREPROD/<timestamp>/results.jtl --script=LNI_PREPROD.jmx
