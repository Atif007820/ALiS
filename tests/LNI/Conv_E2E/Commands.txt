  npm run test --env=ALL --licenseType=ALL --parallel=6

Endorsement Type Override Examples
==================================

Select a specific Residential endorsement:
  npm run test --env=PRE PROD --licenseType RESIDENTIAL --ResType ORC

Select specific Residential and Commercial endorsements in a mixed matrix:
  npm run test --env=PRE PROD,TEST --licenseType=RESIDENTIAL,COMMERCIAL --ResType RC --CommType FC --parallel=2

Select a specific Commercial endorsement:
  npm run test --env=PROD --licenseType=COMMERCIAL --CommType=PASS

Random selection:
  Omit --ResType/--CommType, or leave resType/commType blank in runSettings.json.
  ResType applies only to RESIDENTIAL combinations.
  CommType applies only to COMMERCIAL combinations.

Repeat / Parallel Examples
==========================

npm run test --repeat-each=2
npm run test --env=TEST --repeat-each=2
npm run test --env=PROD --project=chromium --repeat-each=2
npm run test --env=PRE PROD --parallel 3
npm run test --env=PRE PROD --parallel=3
npm run test --env=ALL --licenseType=ALL --parallel=6

Note:
  --parallel controls how many environment/license combinations run at the same time.
  Inside every combination, Script 1 always finishes before Script 2 starts.
  Each combination has isolated saved credentials and test artifacts.
  All combination results are merged into one HTML report, which opens once after the complete matrix finishes.

Login / Entity Name Format
==========================

Login names use this format in TEST, PRE PROD, and PROD:
  Conv_CC_12
  Conv_CC_123
  Conv_CC_1234

The first registration attempt uses 2 digits.
If the login name is taken, retry attempts use 3 digits, then 4 digits, then 5 digits, and so on.
The maximum number of attempts is controlled here:
  runSettings.json -> registrationLoginRetryLimit

Entity names use this format in TEST, PRE PROD, and PROD:
  CONV_DD-MM-YYYY_HH:MM:SS AM/PM

Example:
  CONV_25-06-2026_09:54:12 AM

Notes
=====

- "test" means run Script 1 then Script 2 in serial order.
- Environment and license-type lists create every combination. Example: 3 environments and 2 license types create 6 flows.
- ResType is applied only to Residential combinations; CommType is applied only to Commercial combinations.
- When the applicable endorsement code is blank, the framework selects randomly from its configured pool.
- Use PREPROD inside comma-separated lists. For the spaced name, quote the whole value: --env="PRE PROD,TEST,PROD".
- --parallel controls concurrent combinations; it never changes the Register -> Login/Apply order inside a combination.
- The HTML report opens automatically after the selected run finishes.
- Use npm run report only when you want to reopen the latest report manually.
- Environment names are normalized, so PREPROD and PRE PROD both work.
- PROD existing-owner UBI is configured in editableData.js.
- Questions tab answers still avoid selecting Yes.
