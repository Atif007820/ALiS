# Conveyance approval checklist audit

TEST, 13 November 2026. Read-only inspection of existing New Conveyance
Installation applications. The audit sampled 39 transactions across 26 of the
32 configured endorsement codes. It did not submit or approve the sampled
applications. A row not observed for an endorsement is not proof it can never
appear; the same endorsement can have different rows at different stages or
on different applications.

## Checklist rules

| Checklist item | Observed variation | Automation |
| --- | --- | --- |
| Mandatory plans; additional supporting documents | Present in every sampled record | Existing plan and supporting-document rules |
| Contract review | Seen during intake | Match by row name during intake |
| Application fee review; payment linked to permit | Present on some intake and technical records; missing from others | Handle known rows by name when present, without requiring a fixed count of review rows |
| Blind Hoistway | Present on technical Commercial records across multiple endorsements | Existing completion rule when present at technical review |
| Building Official approval | Observed for LULA, IPL, ISCL and VPL, in intake and/or technical review | Waive only when the saved applicant answer is No or N/A; otherwise leave for review |
| Elevator and General Contractor License validation | Present on some older intake records, including Residential ORC | Pending items require manual review; never mark complete automatically |
| Test Checklist; Mail Paper Copy of Permit or Denial correspondence | Displayed as N/A in sampled records | Leave informational rows alone |
