Conveyance Playwright Commands
==============================

Run from the workspace root or tests/LNI/Conveyance.

npm run conv

The default is AppType=NCI, PerType=Res. The runner uses the single TEST URL
in config/URL.js. Edit that file when the TEST build URL changes.

Application and permit combinations
-----------------------------------
AppType   PerType                 Application
NCI       Comm, Res               New Conveyance Installation
CHI       CPH(A10.4), CMH(A10.5)   Construction Hoist Installation

Select one specific flow:
  npm run conv -- --AppType=NCI --PerType=Comm --CommType=FC
  npm run conv -- --AppType=NCI --PerType=Res --ResType=ORC
  npm run conv -- --AppType=CHI "--PerType=CPH(A10.4)"
  npm run conv -- --AppType=CHI "--PerType=CMH(A10.5)"

Run both New Conveyance permits with specific endorsements:
  npm run conv -- --AppType=NCI --PerType=Comm,Res --CommType=FC --ResType=ORC --parallel=2

Run both hoist permits:
  npm run conv -- --AppType=CHI --PerType=ALL --parallel=2

Run all four supported pairs:
  npm run conv -- --AppType=ALL --PerType=ALL --parallel=4

Run one permit from each application type:
  npm run conv -- --AppType=NCI,CHI "--PerType=Comm,CMH(A10.5)" --CommType=FC --parallel=2

Use quotes around permit arguments containing parentheses. Lists are comma-
separated and case-insensitive. ALL selects all supported choices. Each named
AppType must have at least one compatible PerType. Invalid combinations stop
before Playwright opens a browser. An explicit AppType with no PerType runs
all permits for that application selection; otherwise defaults come from
config/runSettings.json. Command-line values override the settings.

Endorsements
------------
ResType applies only to NCI / Res, and CommType only to NCI / Comm.
Blank selects one available endorsement randomly; use --ResType= or
--CommType= to clear a configured override. CHI never selects an endorsement.
Use a comma-separated list for specific endorsements, or ALL to run each
configured endorsement as its own complete flow:

  npm run conv -- --AppType=NCI --PerType=Comm --CommType=ALL --parallel=4
  npm run conv -- --AppType=NCI --PerType=Comm --CommType=FC,LULA --parallel=2
  npm run conv -- --AppType=NCI --PerType=Res --ResType=ALL --parallel=4

Parallel, browser and repeat options
------------------------------------
Each target runs Register -> Login/Apply -> Approve in order. --parallel=N
limits concurrent full targets. Projects and --repeat-each expand the target
list. Each target uses its own newly registered account and exact transaction
handoff. The latest run is merged into one Playwright report.

  npm run conv -- --AppType=ALL --PerType=ALL --parallel=4 --list
  npm run conv -- --headed --project=chromium
  npm run conv -- --project=firefox
  npm run conv -- --project="Microsoft Edge"
  npm run conv -- --repeat-each=2 --parallel=2
  npm run conv -- --debug --project=chromium

--list shows the plan without signing in, changing records, or replacing the
previous report. In runSettings.json, parallel sets the default concurrency
and parallelWorkers is the limit used by a bare --parallel flag.
Apply and approval require retries=0 to prevent duplicate submissions.

Standalone scripts
------------------
  npm run test -- --spec=register
  npm run test -- --spec=apply --AppType=CHI "--PerType=CPH(A10.4)"
  npm run test -- --spec=approve --AppType=CHI "--PerType=CPH(A10.4)" --transaction=<NUMBER>

Use config/script2LoginCredentials.js for an existing applicant account.
When both fields are blank, apply uses the last successfully registered account
from testData/userData.json. Standalone approval requires one target and an
explicit --transaction or the TransactionNumber in config/approvalTransacNumber.js.
The full flow always uses the current run's captured transaction.

Set CONVEYANCE_APPROVER_LOGIN_NAME and CONVEYANCE_APPROVER_PASSWORD in the
Conveyance .env file for approval. Keep actual credentials out of commands.

Framework shortcuts: test:register, test:apply, test:approve, test:matrix, report.
Workspace shortcuts: conveyance:e2e, conveyance:e2e:headed, conveyance:e2e:list,
conveyance:e2e:matrix, conveyance:approve.

Configuration
-------------
config/URL.js              Single TEST URL
config/runSettings.json    AppType, PerType, ResType, CommType and run options
config/applicationTypes.js Supported application/permit pairs and UI labels
config/editableData.js     Shared inputs and Construction Hoist fields
