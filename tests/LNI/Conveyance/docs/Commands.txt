Conveyance Commands
===================
Run npm run conv from the workspace root or tests/LNI/Conveyance.
Run the framework shortcuts below from tests/LNI/Conveyance.
Add --list after npm's -- separator to preview without signing in, submitting,
approving, or clearing existing reports. IDs in examples are for preview only.
Preview checks command parsing, workflow planning and test discovery. It does not
exercise ALiS forms, credentials, uploads or approval saves.

FLOW COMMANDS
-------------
New applicant and new installation:
  npm run conv initial
  npm run conv var
  npm run conv alt

Existing applicant, new installation:
  npm run conv initial -- --ExistingUser
  npm run conv var -- --ExistingUser
  npm run conv alt -- --ExistingUser

Existing conveyance, apply and approve:
  npm run conv var -- --ExistingConveyance
  npm run conv alt -- --ExistingConveyance
  npm run conv var -- --ExistingConveyance --ConvNum=9790 --list
  npm run conv alt -- --ExistingConveyance --ConvNum=9790 --list

One action only:
  npm run conv -- --register
  npm run conv initial -- --apply
  npm run conv var -- --apply
  npm run conv alt -- --apply
  npm run conv var -- --apply --ConvNum=4749 --list
  npm run conv alt -- --apply --ConvNum=4749 --list
  npm run conv -- --approve
  npm run conv -- --approve --TransacNum=4324 --list

SELECT, PREVIEW, AND RUN
-----------------------
  npm run conv initial -- --apply --AppType=NCI --PerType=Comm --list
  npm run conv initial -- --AppType=NCI --PerType=Res --ResType=ORC --list
  npm run conv var -- --AppType=NCI --PerType=Comm --CommType=FC --list
  npm run conv alt -- --AppType=CHI --PerType=CPH-A10.4 --NoConveyanceChanges --headed --list
  npm run conv alt -- --AppType=CHI --PerType=CMH-A10.5 --list
  npm run conv alt -- --AppType=NCI,CHI --PerType=Comm,CPH-A10.4 --CommType=FC --parallel=2 --list
  npm run conv initial -- --AppType=ALL, PerType=ALL, CommType=FC --parallel 3 --list
  npm run conv alt -- --AppType=ALL --PerType=ALL --ResType=ALL --CommType=ALL --parallel=4 --list
  npm run conv alt -- --apply --NoConveyanceChanges --list
  npm run conv alt -- --ExistingConveyance --NoConveyanceChanges --list
  npm run conv initial -- --AppType= --PerType= --ResType= --CommType= --list
  npm run conv initial -- --headed --project="Microsoft Edge" --list
  npm run conv initial -- --project=chromium --repeat-each=2 --parallel=2 --list
  npm run conv initial -- --debug --project=chromium --list

HOW THE MODES WORK
------------------
initial registers, applies for an installation, and approves it. var and alt
then use the approved Conveyance # to apply for and approve the follow-up.
--ExistingUser skips registration but still creates and approves an installation.
--ExistingConveyance applies for and approves only the variance or alteration.
--apply submits the selected application without approval. With var or alt it
starts on an approved existing conveyance. Do not combine --apply with --ExistingUser.
--approve finds the exact Work Queue transaction and uses its application checklist.
It does not register or apply. --regsiter is a legacy alias for --register.

Alteration fills a random contract value and may change zero or more editable
Conveyance Information fields. --NoConveyanceChanges leaves that section unchanged;
it does not disable the random contract value. This flag only applies to alt.

SELECTION AND CONFIGURATION
---------------------------
NCI: PerType=Comm or Res. CHI: PerType=CPH-A10.4 or CMH-A10.5 (no quotes needed).
The legacy codes CPH(A10.4) and CMH(A10.5) still work, but require quotes in PowerShell.
Use AppType, PerType, ResType and CommType for installations only. CV (Variance)
and CA (Alteration) have no installation selectors of their own.
Lists are case-insensitive and comma-separated. ALL expands the selected axis;
with AppType=ALL, a specific PerType filters the applications. A specific
incompatible endorsement is rejected; ALL warns if it cannot use an endorsement.
CLI choices override runSettings.json. To clear a saved choice, use --Key=.
A valueless selector with --apply inherits the configured choice.

Use an explicit code from ENDORSEMENT TYPES below, a comma-separated list,
or ALL for ResType and CommType.

Existing applicants: config/LoginCredentials.js or LOGIN_NAME / LOGIN_PASSWORD.
CLI --LoginName and --LoginPassword take priority; prefer local config or env,
because command-line passwords can be visible in logs and shell history.
Existing conveyances: config/ConveyanceVarianceDetails.js for var, or
config/ConveyanceAlterationDetails.js for alt. --ConvNum overrides the selected file.
Approval only: config/approvalTransacNumber.js; --TransacNum overrides the file.
Approver login: local .env, CONVEYANCE_APPROVER_LOGIN_NAME and CONVEYANCE_APPROVER_PASSWORD.
Forms and upload comments: config/editableData.js. Upload steps choose from
the files in UploadFiles at runtime; place only supported files there.
Approval checks randomly choose Complete or Waived Off when both are enabled.
If only one is enabled it is used. Pending is never selected.
TEST URL: config/URL.js. Browsers, parallel defaults and timeouts: config/runSettings.json.

--parallel=N or --parallel N caps concurrent combinations. Each combination's
stages run in order. --serial limits combinations to one. --workers sets
Playwright workers per stage. --project selects chromium, firefox or "Microsoft Edge";
--repeat-each repeats each target. Direct follow-ups on an existing conveyance
and approval-only accept one browser project and one repeat. Apply and approval require retries=0.

SHORTCUTS AND REPORTS
--------------------
  npm ci
  npm run setup
  npm run validate:flows
  npm run report
  npm run clean
  npm run test -- --spec=register --list
  npm run test -- --spec=apply --AppType=CHI --PerType=CPH-A10.4 --list
  npm run test:list
  npm run test:matrix -- --list

Legacy aliases: npm run test:register, test:apply, test:serial, test:headed,
test:debug, test:all, test:chrome, test:firefox and test:edge. The old mixed
matrix includes NCI, CHI, CV and CA. --AppType=CV and --AppType=CA are shorthand
for var and alt when used without a flow name. Workspace-root aliases:
conveyance:e2e, conveyance:e2e:headed, conveyance:e2e:list and conveyance:e2e:matrix.
The latest test results are merged into one HTML report; npm run report reopens it.
