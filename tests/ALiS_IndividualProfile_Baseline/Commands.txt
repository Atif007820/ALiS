  --flow=2      Existing Profile - Modify
  --flow=3      New Profile - View
  --flow=4      Existing Profile - View
  --flow=1,2    Modify flows only
  --flow=3,4    View flows only

Four-worker Execution
---------------------
All flows and test cases with up to four independent jobs:
  npm run baseline -- --flow=all --bu=MAMMO --url=NVRCP --tc=all --project=chromium --parallel=4

Multiple browsers with four workers:
  npm run baseline -- --flow=all --bu=MAMMO --url=NVRCP --tc=all --project=chromium,msedge --parallel 4

Preserve previous results while verifying:
  npm run baseline -- --flow=all --bu=MAMMO --url=NVRCP --tc=all --project=chromium --parallel=4 --output-dir=test-results/my-verification --open-playwright-report=false

Bare --parallel uses parallelWorkers in config/runSettings.json (default 4).
--serial uses one worker. Existing-profile jobs sharing the same portal/name
are protected from concurrent modification across browsers and flows.
New-profile jobs on the same portal/account are serialized to protect credential
session state. Other jobs fill available slots; this does not force unsafe work
to overlap. Each browser job gets independent generated profile data.
API numbers use API plus 12 random digits (15 characters), and credential numbers
use 12 random digits. Both are reserved within a run and verified before Save;
they do not depend on timestamps or get truncated like the previous API values.
Locks and generated-name reservations apply within one runner, not separate CLI runs.

Credential selections are rechecked after postbacks before popup OK. The popup
and parent callback must finish before proceeding. Runtime retries reuse the
created profile after Save, with separate retry folders and failure traces.
Open a failure trace with:
  npx playwright show-trace "FULL_PATH_TO_runtime-trace.zip"
openPlaywrightReport in config/runSettings.json controls aggregate report opening.
UI wording/required-field differences remain comparison failures; baselines are
not automatically changed to make tests pass.


Mammo Commands
--------------
Mammo, all four flows, all test cases:
  npm run baseline -- --flow=all --bu=MAMMO --url=NVRCP --tc=all --project=chromium

Mammo, New Profile - Modify:
  npm run baseline -- --flow=1 --bu=MAMMO --url=NVRCP --tc=all --project=chromium

Mammo, Existing Profile - Modify:
  npm run baseline -- --flow=2 --bu=MAMMO --url=NVRCP --tc=all --project=chromium

Mammo, New Profile - View:
  npm run baseline -- --flow=3 --bu=MAMMO --url=NVRCP --tc=all --project=chromium

Mammo, Existing Profile - View:
  npm run baseline -- --flow=4 --bu=MAMMO --url=NVRCP --tc=all --project=chromium

Mammo, headed mode:
  npm run baseline -- --flow=all --bu=MAMMO --url=NVRCP --tc=all --project=chromium --headed

Mammo, Existing Profile - Modify with temporary profile override:
  npm run baseline -- --flow=2 --bu=MAMMO --url=NVRCP --entity="IND_1 MAMMO_1" --tc=all --project=chromium

Mammo, Existing Profile - View with temporary profile override:
  npm run baseline -- --flow=4 --bu=MAMMO --url=NVRCP --entity="MAMMO_1,IND_1" --tc=all --project=chromium
